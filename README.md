# Mahrcus Leanard Usisa — Web Portfolio

A responsive personal portfolio built with HTML, CSS, and JavaScript for GitHub Pages.

## Publish with GitHub Pages

1. Create a public repository named `mldusisa.github.io`.
2. Upload all files and folders from this ZIP to the repository root.
3. Open **Settings → Pages**.
4. Select **Deploy from a branch**.
5. Choose the `main` branch and `/ (root)` folder.
6. Save and wait for deployment.

Your website should appear at:

https://mldusisa.github.io

## Main files

- `index.html` — website content
- `style.css` — design and responsive layout
- `script.js` — theme toggle, animations, certificate viewer, contact form
- `assets/images/certificates/` — certificate images
- `assets/documents/` — downloadable CV

## Updating content

Edit the files, commit the changes, and push them to GitHub. GitHub Pages will automatically redeploy the website.
